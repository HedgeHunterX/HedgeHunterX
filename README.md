# Hi, I'm Sai Manish 👋

**Threat Detection Engineer** at Resillion, building and tuning detections for a multi-client SOC.

I write KQL detection rules and threat hunts for Microsoft Sentinel and Microsoft Defender XDR, and automate response with SOAR. My focus is detections that fire on real threats, not noise.

## What I work on

- **Detection engineering:** Sentinel analytics rules, Defender XDR custom detections, NRT rules
- **Alert tuning:** finding the root cause of false positives and fixing the logic, not just adding exclusions
- **Threat hunting:** turning new threat intel into hunts across Defender XDR and Sentinel
- **Cloud and identity:** Entra ID, Microsoft 365, Azure, AWS CloudTrail and GCP audit logs
- **Log health:** ingestion and connector monitoring, so missing data does not mean missing attacks
- **SOAR:** automating triage and enrichment
- **Detection as code:** a central Azure DevOps repo to version, review and deploy detection rules across multiple client environments
- **Vulnerability management:** Qualys and Nessus scanning, and tuning detections around authorised scanner activity
- **Malware analysis:** dynamic (sandbox) analysis of suspicious files to pull out behaviour and IOCs for new detections
